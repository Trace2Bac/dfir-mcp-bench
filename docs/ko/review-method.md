# 모델 실행 결과를 검토하는 방법

모델 실행은 자동으로 채점하지 않는다. 검토자가 보고서에서 질문마다 답을 읽고, mulder가 자기
실행에 쓰는 척도로 판정을 하나 준다.

| 판정 | 기준 |
|---|---|
| found | 정답지의 사실을 답했다. |
| partial | 일부만 답했다. 질문이 요구하는 사실 중 일부, 또는 날짜는 맞고 시각이 틀린 경우. |
| missed | 답이 없거나, "확인 불가", 추측, 틀린 값. |
| false positive | 증거와 반대되는 내용을 사실로 단정했다. 예: 캡처 파일이 있는데 "캡처 파일이 없다". |

보고서가 답 밖(발견 사항이나 요약)에서 이런 단정을 하면 그것도 오탐으로 세고, 실행의
`review.yaml`에 `extra_false_positives`로 적는다.

실행마다 세 가지 비율을 질문 수로 나눠 계산한다.

- 완전 일치: found
- 탐지: found 또는 partial
- 오탐: false positive 판정과 답 밖의 오탐

실험 페이지에는 검토한 실행의 중앙값과 괄호 안에 범위를 보인다. 두 라벨의 범위가 겹치지 않을
때만 개선이라고 한다.

답이 판단인 질문(예: "컴퓨터에 바이러스가 있는가?")은 사건 파일에 `review_only`로 표시하고 자동
확인을 하지 않는다. 단정하지 않은 답이나 도구 결과를 그 한계와 함께 보고한 답은 missed이고, 증거와
반대되는 단정만 오탐이다.
