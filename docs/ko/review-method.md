# 테스트 결과를 검토하는 방법

검토자가 보고서에서 질문별 답을 읽고 판정합니다. `review.yaml`에는 괄호 안의 영어 값을 적습니다.

| 판정                    | 기준                                                       |
| ----------------------- | ---------------------------------------------------------- |
| 일치 (found)            | 정답지의 사실을 답했습니다.                                |
| 부분 (partial)          | 질문이 요구하는 사실 가운데 일부만 맞게 답했습니다.        |
| 놓침 (missed)           | 답이 없거나, "확인 불가"라고 했거나, 추측이나 틀린 값입니다. |
| 오탐 (false positive)   | 증거와 반대되는 내용을 사실처럼 단정했습니다.              |

답이 아닌 보고서의 발견 사항에서 잘못된 내용을 단정한 경우도 오탐으로 세고, `review.yaml`의
`extra_false_positives`에 적습니다.

실행마다 세 가지 비율을 질문 수로 나눠 계산합니다.

- 완전 일치: 일치
- 탐지: 일치 또는 부분
- 오탐: 오탐 판정과 답 밖의 오탐
