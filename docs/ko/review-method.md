# 테스트 결과를 검토하는 방법

검토자가 보고서에 적힌 질문별 답을 읽고 판정합니다.

| 판정           | 기준                                                        |
| -------------- | ----------------------------------------------------------- |
| found          | 정답지의 사실을 답했습니다.                                 |
| partial        | 일부만 답했습니다. 질문이 요구하는 사실 중 일부만 맞습니다. |
| missed         | 답이 없거나, "확인 불가", 추측, 틀린 값입니다.              |
| false positive | 증거와 반대되는 내용을 사실로 단정한 경우입니다.            |

보고서가 답 밖의 발견 사항에서 잘못된 내용을 단정해도 오탐으로 세고,
`review.yaml`에 `extra_false_positives`로 적습니다.

실행마다 세 가지 비율을 질문 수로 나눠 계산합니다.

- 완전 일치: found
- 탐지: found 또는 partial
- 오탐: false positive 판정과 답 밖의 오탐
