## Third-party material

Some files in `experiments/` hold material that is **not** covered by this repository's licenses.

| Material | Where | Terms |
|---|---|---|
| Excerpts of evidence (file names, strings, packet fields) in tool output | `transcript.jsonl`, `answer.md`, `mulder/` report files of each run | The dataset's own terms; each case and dataset links its source |
| Reports, logs and audit records produced by mulder | the `mulder/` folder and `server-db/` of each run | Output of mulder (calebevans/mulder, Apache-2.0), kept unchanged as the record of the run |

The evidence itself is never redistributed. The datasets used so far:

| Dataset | Source | Notes |
|---|---|---|
| Rhino Hunt (DFRWS 2005 Rodeo) | NIST CFReDS, https://cfreds-archive.nist.gov/dfrws/Rhino_Hunt.html | Downloaded by `datasets/rhino-hunt/fetch.sh` |
| NIST CFTT deleted file recovery (DFR) images | NIST CFReDS, https://cfreds-archive.nist.gov/dfr-test-images.html | Downloaded by `datasets/nist-cftt-dfr/fetch.sh` |
| NIST Hacking Case | NIST CFReDS, https://cfreds-archive.nist.gov/Hacking_Case.html | Downloaded by `datasets/nist-hacking-case/fetch.sh`; names in the image are fictional |
| Synthetic DNS and SMTP capture | generated by `datasets/synthetic-dns-smtp/make_pcap.py` | Covered by this repository's licenses |

When you add a dataset, add a row here with its source.
